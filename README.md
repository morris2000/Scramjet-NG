# Scramjet-NG

Next Generation Web Proxy Compatibility Layer based on MercuryWorkshop Scramjet.

## Goal

Scramjet-NG extends Scramjet with a compatibility layer for modern dynamic web applications.

The project focuses on:

- SPA compatibility
- Fetch and streaming fetch
- Server-Sent Events
- WebSocket
- Dynamic import
- Web Worker
- Storage and origin virtualization
- Browser API compatibility testing

## Architecture Principle

Scramjet-NG is not a replacement for Scramjet.

The design keeps Scramjet core components and adds:

- compatibility patches
- runtime adapters
- diagnostics
- regression tests
